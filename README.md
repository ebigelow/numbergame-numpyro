# Number game model implemented in numpyro

Independent probabilities model of the number game from [Bigelow & Piantadosi (2016)](https://colala.berkeley.edu/papers/bigelow2016inferring.pdf), implemented in numpyro. Results closely match our original implementation - see `analysis_human.ipynb`.

I originally wrote this for [Bigelow*, Wurgaft* et al. (2025)](https://arxiv.org/abs/2511.00617) with help from YingQiao Wang, but it never ended up in that paper.
